# PI·侧边栏笔记（Notes）— PI-Desktop 插件

右侧工作面板里的笔记：按项目分开的笔记列表 + 一个跨项目的收件箱，Markdown 编辑与预览，自动保存。

![视图位置](https://img.shields.io/badge/PI--Desktop-%E2%89%A50.9.0-blue) ![权限](https://img.shields.io/badge/permissions-ui.view%20%2B%20clipboard.write-lightgrey)

## 它做什么

- **停靠在右侧工作面板**：和 Git、文件管理器、终端并列，点「新建 → 笔记」打开，跟随当前会话。
- **列表 ⇄ 编辑器双态**：窄栏一屏只看一件事；列表带搜索、置顶、更新时间，编辑器带面包屑、编辑/预览滑块、置顶、复制、删除。
- **编辑 / 预览是滑块**：「编辑 ⇄ 预览」用分段滑块切换，选中块是纯色块（`--bg` + 发丝描边，沿用旧页签选中块的配色），选中文字用正文色、未选中灰色，位移是 stiffness≈400 / damping≈30 手感的弹簧；收件箱 / 项目 / 全部 三档页签用的是同一套外观。
- **可调缩放**：列表与编辑器顶栏各有一个放大镜入口；手动 80%–160%（5% 步进），或「自适应」跟随面板宽度自动取值（约 86%–134%）。也支持 `Ctrl/Cmd+滚轮` 随时缩放，并弹出当前百分比。
- **深浅模式切换**：顶栏右侧的太阳/月亮按钮在浅色与深色之间切换（默认跟随宿主外观，手动切过之后以本地偏好为准，关掉视图再打开仍然生效）。
- **按钮提示从上方浮出**：所有图标按钮悬停/聚焦时在按钮上方弹出带指向箭头的气泡（顶部空间不足时自动落到下方，并夹在视口内），320ms 延迟 + 果冻回弹入场。
- **卡片式列表**：每条笔记是一张卡片（中性底 + 发丝描边，hover 抬一档），标题、摘要、更新时间都在卡片内。
- **按项目隔离 + 全局收件箱**：顶部三档范围（收件箱 / 项目 / 全部）。项目键是规范化后的工作区路径，同一个项目重新打开时笔记自动回来；「全部」能看到其他项目的笔记。
- **Markdown 编辑 + 预览**：标题、粗体/斜体/删除线、行内代码与代码块、有序/无序列表、任务清单（`- [ ]` / `- [x]`）、引用、分隔线与链接。
- **预览可交互**：预览里的任务清单方框可直接点选，按行回写正文的 `[ ]` / `[x]` 并立即保存；代码块右上角有复制按钮，点一下复制该块代码。
- **自动保存 + 手动保存**：输入后 600ms 落盘，失焦、返回列表、切换笔记、隐藏窗口都会立即保存；顶栏还有保存按钮（有改动时图标变强调色），状态栏显示「未保存 / 保存中 / 已保存 HH:MM」。
- **行号 + 界面字体正文**：编辑态左侧有行号槽，长段落折行后编号仍与行首对齐（按隐形镜像逐行量高度）；正文用 MiSans，与预览一致，代码块仍用 JetBrains Mono。
- **跟着侧边栏自适应**：面板拖宽拖窄即时重排（`ResizeObserver` + `window.resize`）。窄于 300px：`新建` 只留图标、页签计数隐藏、行号槽收窄；窄于 240px：搜索框独占一行、操作按钮收到第二行右对齐。超宽时内容列按 780px 居中、搜索框与页签封顶 480px、`新建` 贴右边，行宽不会拉成一条线。卡片与正文始终保留 10–14px 内边距；缩放还会按面板宽度封顶。
- **未保存提示**：有改动时返回列表 / 按 Esc 离开，会弹「有未保存的修改」，可选保存并离开、放弃修改或取消；弹层期间自动保存暂停，选「放弃」就是真的丢掉这次改动。
- **卡片上直接置顶**：卡片右上角的图钉可以直接点（未置顶的卡片悬停时才显示），点完在「置顶 / 笔记」分组间移动。
- **删除可撤销**：删除后 6 秒内点「撤销」即可恢复。
- **自动快照**：每次写盘前按 10 分钟间隔留一份快照，保留最近 5 份；`notes.json` 损坏时自动回退到最新可用快照。

## 安装

**开发加载（推荐用于调试）**

1. 打开 PI-Desktop → **扩展**（Extensions）。
2. 右上角的 ⋯ 菜单 → **加载本地插件**，选择本目录（含 `manifest.json` 的那一层）。
3. 审阅并授予 `ui.view`、`clipboard.write`。
4. 打开任意会话，在右侧工作面板的「新建」菜单里选「笔记」。

之后改动目录里的文件会在约 300ms 后热重载（`unload → 校验 → load`，面板内存不保留）。

**安装包**

```bash
pnpm pi-plugin check .
pnpm pi-plugin pack .
# → dist/io.github.g1oow.sidebar-note-0.1.0.piplug
```

然后在 **扩展 → ⋯ → 安装插件包** 里选择生成的 `.piplug`（store-only ZIP，必须用 devkit 打包）。
**调试：`diagnostics.log`**

面板每次启动和尺寸变化，都会把自己的真实布局写进插件数据目录（`<PI 数据目录>/plugins/data/io.github.g1oow.sidebar-note/diagnostics.log`），每行一条 JSON：

| 字段 | 含义 |
|---|---|
| `panelWidth` | 视图认为的面板宽度（= `min(body, innerWidth, visualViewport)`） |
| `bodyWidth` / `innerWidth` / `visualWidth` | 三个来源各自的宽度，用来判断谁更窄 |
| `docScrollWidth` | 文档实际宽度：大于 `panelWidth` 就是横向溢出（被裁） |
| `shellClientWidth` / `shellScrollWidth` | `.shell` 的布局像素（已除以缩放）：两个值不等才是视图内部溢出 |
| `zoom` / `dpr` | 当前缩放百分比与设备像素比 |
| `narrow` / `tiny` / `tight` | 窄面板 / 极窄 / 编辑器顶栏紧凑态是否命中 |

「右侧被裁」的判据是 `docScrollWidth > panelWidth`：文档真的横向溢出了。注意 `shellClientWidth` / `shellScrollWidth` 是 `.shell` 在 `zoom` 之前的布局像素，恒等于 `panelWidth / zoom`，所以**只能彼此比较**；拿它和 `panelWidth` 比会把正常缩放误判成溢出（364px 面板在 95% 下读到的就是 384）。

每次会话最多 40 条，超过 64 KiB 自动只保留后半；**不记录任何笔记内容**。


## 命令与快捷键

| 触发 | 效果 |
|---|---|
| 命令 `Notes: Open notes` / `笔记：打开笔记`（Ctrl+K 搜索） | 聚焦已打开的笔记视图 |
| 设置项「打开笔记的快捷键」，默认 `Mod+Shift+N` | 同上，仅在 PI-Desktop 窗口获得焦点时生效 |
| `Ctrl/Cmd+N` | 新建笔记（当前范围） |
| `Ctrl/Cmd+F` | 回到列表并聚焦搜索框 |
| `Ctrl/Cmd+S` | 立即保存（等同顶栏的保存按钮） |
| `Esc` | 编辑器内返回列表；搜索框内清空关键词 |
| `Ctrl/Cmd+滚轮` | 缩放界面（5% 步进，80%–160%），底部弹出当前百分比 |

> 「`Ctrl/Cmd+…`」类快捷键与 `Ctrl/Cmd+滚轮` 只在**鼠标点过插件面板、面板仍持有焦点**时生效（`Esc` 除外，它只作用于视图内部）。这样不会抢宿主的全局快捷键。

## 设置

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `openShortcut` | shortcut | `Mod+Shift+N` | 绑定到命令 `note.open`。这类快捷键是**应用内**的，不是 OS 全局热键。 |

## 权限

| 权限 | 风险 | 用途 |
|---|---|---|
| `ui.view` | 低 | 提供工作面板视图；`pi.ui.revealView` 聚焦它 |
| `clipboard.write` | 中 | 仅在用户点「复制正文」或点击预览里的链接时写入剪贴板 |

不申请：`fs.*`（不读写你的工作区文件）、`net.*`（`manifest.net.domains` 未声明 = 无出网）、`clipboard.read`、`notify`、`agent.*`。

## 数据存哪里

- 位置：`pi.plugin.getDataPath()` 给出的插件私有目录（通常在 PI-Desktop 数据目录下的 `plugins/data/io.github.g1oow.sidebar-note/`）。
- 文件：`notes.json`（`{ schema: 1, notes: [...] }`）+ `snapshots/*.json`。
- 写入方式：临时文件 → `fsync` → `rename`，中断不会留下半写文件；写盘前按需留快照。
- 界面偏好（范围、预览开关）存在视图页自己的 `localStorage`，不写进笔记文件。

卸载插件会删除该目录，需要保留时先「复制正文」或备份 `notes.json`。

## 容量与限制

| 项 | 上限 |
|---|---|
| 单条正文 | 200,000 字符（超出截断） |
| 单条标题 | 200 字符 |
| 笔记总数 | 5,000 条 |
| 撤销删除窗口 | 60 秒（提示条 6 秒后消失，期间点「撤销」即可） |

## 已知行为

- **预览里的链接不会直接打开浏览器**：视图是沙箱页面，`window.open` 被宿主拒绝。点击链接会把 URL 复制到剪贴板，粘贴到浏览器即可（hover 提示如是说明）。要真正打开需要额外申请 `shell.openExternal`。
- 视图 tab 属于会话：没有打开任何会话时，命令只能给出提示，无法凭空开出面板。
- 笔记按工作区分开：同一目录以不同路径形式（大小写、分隔符、尾斜杠）打开时，键会归一化后再比较，指向同一份笔记。
- 同一个笔记在两个视图里同时编辑时，以最后一次保存为准（没有冲突合并）。
- 缩放偏好（自适应 / 手动数值）存在视图页的 `localStorage`，不进笔记文件；「自适应」按面板宽度线性取值，手动范围 80%–160%。
- 提示气泡优先出现在按钮上方；顶栏按钮上方就是窗口边缘、物理上没有空间，此时自动落到按钮下方（入场动画仍是从上往下落）。

## 视觉

| 项 | 采用 | 说明 |
|---|---|---|
| 字体 | **MiSans**（界面）+ **JetBrains Mono**（正文与代码） | 只按系统字体名引用，**不打包字体文件**：MiSans 单字重约 8 MB，整族远超 `.piplug` 的 50 MiB 上限。用 `@font-face { src: local(...) }` 把 Light/Regular/Medium/Semibold 绑到 300/400/500/600/700，系统没装时自动落到无衬线回退栈。 |
| 配色 | **OpenCode** 双调色板 | 深色：`#121212` 底（比宿主 OpenCode 的 `#0a0a0a` 亮一档，否则插件面板和宿主背景融成一片）、`#1a1a1a` 栏与卡片、`#242424` 字段、紫 `#9d7cd8`、薄荷 `#7fd88f`、琥珀 `#f5a742`；浅色：白底、标题 `#b06915`、代码 `#27793d`、链接 `#2c66b8`。语义映射对齐 OpenCode 的 markdown 规则：标题=accent、粗体=琥珀、斜体=小麦、行内代码=薄荷/玉绿、链接=青蓝、无序标记=蜜桃。 |
| 图标 | **Iconoir**（MIT） | 8 个图标（search / plus / nav-arrow-left / pin / copy / trash / page / check / zoom）以内联 `<symbol>` sprite 打包，描边 1.5、24 网格，随 `currentColor` 变色，**无任何外链请求**。 |
| 组件 | 参考 **Obsidian** | 发丝分隔线、6px 圆角、hover 只给一层极浅底色、无渐变无重投影；列表行、分段式范围切换、实心勾选框、左侧竖线引用块、细滚动条。 |
| 动效 | **Motion 风格**（自实现） | 分段滑块用纯色块 + 260ms 弹簧位移（对应示例的 `stiffness:400 / damping:30`）；开关与气泡/面板入场同样是透明度 + 位移的弹簧曲线。宿主不允许运行时拉 CDN，所以弹簧是 CSS 曲线而非 motion 库，`prefers-reduced-motion` 时全部关闭。 |

## 开发

```text
manifest.json        插件身份、视图/命令/设置贡献、权限
main.js              插件进程：数据读写、note:* 通道、命令注册
views/index.html     视图页骨架
views/styles.css     视图样式（light/dark 双套变量）
views/app.js         视图逻辑：列表、编辑器、Markdown 渲染、自动保存
```

- 视图页只有 `window.pluginBridge`，没有 `pi`：内置通道（`app.getAppearance`、`workspace.get`）走宿主，其余 `note:*` 通道由 `main.js` 的 `onPanelInvoke` 处理。
- 所有用户文本都通过 `textContent` / text node 渲染，从不拼 `innerHTML`；链接只接受 `http(s):` 与 `mailto:`。
- 无外部依赖、无构建步骤：产物就是上面这些可直接执行的 JS/HTML/CSS，图标也是内联的，运行时没有任何网络请求。
